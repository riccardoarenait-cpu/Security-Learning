# AI Basics

AI is a machine or compute system ale to carry out tasks that would otherwise require human reasoning, comprehension, problem solving

Machine learning is the computer's capability to learn from data without being given instructions

ML follows a lifecycle, it's not a one time operation, it starts from defining the problem, collecting and preparing data until it performs well

Overfitting = when the model becomes too familiar with the training data that it fails with new data

ML algorithm structure : 

- Decision process = makes predictions based on input data

- Error function = evaluates how far off the predictions were

- Model Optimization process = adjust algorithms to do better

Deep Learning = neural networks with more than 3 layers that doesn't require labelled data, no human intervention makes it much more scalable

Large Language Models: DL models that generate text by predicting the next word in a sequence, when using a chatbot, the answer given is a rapid series of predictions; they're trained with huge volumes of text,
