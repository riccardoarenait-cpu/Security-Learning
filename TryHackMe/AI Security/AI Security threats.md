# AI Security threats

MITRE ATLAS : Similar to the ATT&CK framework but specifically built for AI models

Five key vulnerabilities :

- Prompt injections = when a user overrides initial instructions given to a model with a prompt, that can reveal sensitive information like the underlying infrstructure

- Data poisoning = when an attacker tampers with training data of a module, changing its outputs to benefit his own intentions

- Model theft = when an attacker gains unauthorized access to a model and steals intellectual property

- Privay leakage = when an AI accidentally reveals sensitive information from its data

- Model drift = when the model doesn't catch up with modern day technology and fails to perform

AI Enhanced attacks :

- Malware generation = AI can generate a lot of code in seconds, it doesn't require skills

- Deepfakes = Pretending to be someone else

- Phishing = AI can generate the perfect phishing email and send it on a large scale

------------

### Securing AI

- Control who can interact with your systems, strong authentication, strict permissions

- Encrypting sensitive data such as training data

- Following frameworks for AI systems like  ISO/IEC 27090

- Constant monitoring of a model
