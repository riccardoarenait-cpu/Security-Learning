# SIEM

SIEM solutions are very important for security operations, they bring multiple benefits into log analysis

- Centralisation : Every events from multiple sources available in one dashboard

- Correlation : piecing together multiple events to get a better understanding of what's happening

- Historical events : Looking at past events to show threats that might've started earlier

  ------------

  ### Log sources

  - Host based log sources = they come from individual devices : authentication, system events, account management, object access, process auditing
 
  - Network based log sources = they come from network devices : IDS IPS, Firewall, DNS logs, proxy server, router, VPN
 
  - Web based log sources = they come from web applications : WAF logs, CDN, Load balancer, API
