Host centric logs = generated by individual devices (workstations, laptops, servers), view what's happening on the machine

operating system logs, application logs, security tool logs

Network centric logs = what's happening between devices, src, dest IP's, action taken

IDS, IPS, Firewalls, Routers, Switches, web proxies

The perimeter = hardware devices at the edge of a network, gatekeepers, security controls

**SIMULATION** 

in thi simulation I analyzed IDS, Firewall and VPN logs to search for reconnaissance attempts, VPN brute force and credential access, lateral movement, C2 beaconing, Data exfil attempts
