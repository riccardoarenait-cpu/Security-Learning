**Elasticsearch, Logstash, and Kibana**

commonly used tools to collect, store, analyse, and visualise data, SIEM solution

Elasticsearch = search and analytics engine for JSON formatted documents, stores, analyzes data

Logstash = data processing engine that takes data from different sources, filters and sends it to the destination

Beats = data shippers sending data to elasticsearch

Kibana = web based data visualization
