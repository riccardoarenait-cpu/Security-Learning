# Cyber kill chain

Reconnaissance = research and planning, gather detail, informations, oisnt

weaponization = crafting malware and exploits into payloads

delivery = the payload is transmitted to the target environment

exploitation = the attacker's code gets executed on the target machine, the attacker exploits software, services, gains lateral movement

installation = the attacker installs persistent backdoor, web shell, modify windows services

command and control = channel to remotely control and manipulate the victim, http/s, DNS tunneling

actions on objectives = collect user credentials / priviledge escalation / internal recoinnassance / latera movement / exfiltrate data / delete backups and shadow copies / overwrite data
