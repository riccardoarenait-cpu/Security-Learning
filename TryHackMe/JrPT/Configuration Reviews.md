# Configuration Reviews

Configuration based priviledge escalation : works on patched systems, most common and reliable, targets admin decisions

Configuration Review : an audit of a host's settings, permissions, policies, services trying to identify security risks

CIS benchmarks : security baseline recommendations, level 1 and level 2

DISA STIGs : hardening requirements for government and military systems

Automatic auditing tools : 

- Nessus = vulnerability and compliance scanning

- Lynis = open source security auditing for Unix systems

- OpenSCAP = security configuration policies

Host misconfigurations : users and groups, file permissions, services, scheduled tasks
