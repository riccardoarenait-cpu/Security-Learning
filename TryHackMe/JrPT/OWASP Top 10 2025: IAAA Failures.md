# OWASP Top 10 2025: IAAA Failures

OWASP = Organization dedicated on improving security of software and applications

OWASP Top 10 = 10 most critical security risks in applications

IAAA failures are in the OWASP top 10

IAAA = Identity, Authentication, Authorizzation, Accounting

-------------

### Broken access control A01

When the server doesn't enforce who can access a resource

Most common = IDOR

-----------

### Authentication failures A07

When the application can't reliably verify a user's identity

-----------

### Logging and alerting failures A09

When the application doesn't properly record security events
