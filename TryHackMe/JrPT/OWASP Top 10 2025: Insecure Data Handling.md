# OWASP Top 10 2025: Insecure Data Handling

In this room I learned about 3 of the OWASP top 10 vulnerabilities of 2025 related to improper data handling

### A04 Cryptographic failures

When sensitive data isn't protected due to lack of encryption, hashing, or using weak algorithms

How to prevent : use modern secure algorithms

### A05 Injection

When an application mishandles user input by passing it directly into the system without validating it

How to prevent : Treat every user input as untrusted an validate it

### A08 Software or data integrity failures

When an application relies on code, updates that it assumes are trusted, failing to validate data can lead to execution of malicious updates

How to prevent : Establishing boundaries, integrity cehcks
