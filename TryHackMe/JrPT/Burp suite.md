# Burp suite

Java based framework for conducting web application tessting

Burp commmunity 

proxy = interception and modificaion of requests and responses

Repeater = capturing, modifying, resending same requests a lot of times

Request list, request controls, request and response view, layout option, inspector, target

Intruder = spraying endpoints with requests, repetitive testing, request modification

Sniper attacks iterates the payloads, structured attack, battering ram sends all payloads simultaniously, pitchfork simultanious testing of multiple positions in different payloads, cluster bomb 

combines sniper and pitchfork

Decoder = decode captured information

Comparer = compares information

Sequencer = ranomly generated data
