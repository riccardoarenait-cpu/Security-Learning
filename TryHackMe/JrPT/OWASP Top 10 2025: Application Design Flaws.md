# OWASP Top 10 2025: Application Design Flaws

In  this room I learned about 4 of the OWASP top 10 categories related to failures in architecture and design

### AS02 Security misconfigurations

When systems, servers or applications are deployed with unsafe settings or exposed services

Every small misconfiguration can give attacker a way into he system or expose private information

### AS03 Software Supply Chain Failures

When applications rely on systems, components, models that are compromised or oudated

Applications are built from many third party packages, one compromised dependency can affect thousands of organizations

### AS04 Cryptographic Failures

When encryption is used incorrectly or not at all

Web applications rely on cryptography everywhere : protecting traffic, storing data, identities; when these controls fail, sensitive data can be exposed allowing takeover

### AS06 Insecure Design

When flawed logic or architecture is build into a system from the start

You can't patch a design, the only way to fix it is rewiring the system
